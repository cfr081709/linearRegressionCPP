### Simple Linear Regression

This project implements simple linear regression using vector-based operations.

- Takes in vector arrays of input values and output values
- Computes the best-fit line using least squares minimization
- Generates predictions based on the linear equation:
  
  y = mx + b

- Calculates model error using least mean squared error
- Supports prediction of new values using learned slope and intercept

For more details on the implementation, refer to the source code documentation.
